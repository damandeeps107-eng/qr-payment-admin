# Admin Payment QR Dispatcher Panel

Standalone Admin Dashboard application for receiving client payment requests, attaching/dispatching custom QR images, and verifying UTR numbers.

## Features
- Admin PIN Security (`1234`)
- Real-time client request feed
- 1-click QR image attachment & dispatch to requesting client
- Payment verification (Approve / Reject UTR)

## Run
```bash
npm install
node server.js
```
Open `http://localhost:3000`
